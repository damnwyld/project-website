# Hausprojekt-Website
1. `assets/logo.png` durch euer Logo ersetzen (PNG mit Transparenz).
2. Texte, Name, Adresse, Impressum und Datenschutz anpassen.
3. Bilder als `assets/bild1.jpg` usw. ablegen (siehe galerie.html).
4. Farben oben in `style.css` unter `:root` ändern.
5. GitHub: Repo anlegen, Dateien hochladen, unter Settings → Pages → Branch `main` / Ordner `/ (root)` wählen.
